# Magical Mushroom Cluster

Small procedural forest asset created in Blender 4.5.13 LTS for Protea's second scene.

- Source: `magical-mushroom.blend`
- Runtime asset: `magical-mushroom.glb`
- Preview: `preview.png`
- Scale: meters; approximately 45 cm tall
- Origin: center of the moss base at ground level
- Geometry: 2,200 vertices / 4,248 triangles
- Materials: stem, cap, glow, moss, and rock
- External textures: none

The `.blend1` file is Blender's automatic backup of the preceding save.
