# Forest rocks

Three stylized slate-blue rocks with weathered irregular geometry, subtle fissure shading and patchy green moss. Built in Blender 4.5.13 using `scripts/forest-rocks.py`.

- `boulder.glb`: large rock, 1,620 triangles.
- `flat_stone.glb`: flattened rock, 1,820 triangles.
- `small_rock.glb`: small rock, 1,620 triangles.
- `forest-rocks-pack.glb`: arranged set, 6 meshes and 5,060 triangles, approximately 166 KiB.
- `forest-rocks.blend`: editable source with latest Forest_Rocks_Studio scene active; prior scenes retained.
- `preview.png`: 600px EEVEE preview.

Individual GLBs have roots at ground center, meters and Y-up. Color is carried by vertex attributes; no external textures. Lights and camera are excluded from GLBs. Number-suffixed GLBs and blend1 files, when present, are intermediate exports/backups; use filenames above.

Visual preview and export geometry checked. Application integration is pending.
